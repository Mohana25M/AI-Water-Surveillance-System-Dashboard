💧 AI Smart Water Surveillance System

Final Year Project

📖 Project Description

The AI Smart Water Surveillance System is an intelligent monitoring platform designed to monitor the quality and level of water in overhead tanks. The system uses sensors, ESP32, Firebase Cloud and Artificial Intelligence to provide real-time monitoring, prediction and alerts.

🎯 Objectives

  • Monitor Water Level
  • Monitor pH
  • Monitor TDS
  • Monitor Turbidity
  • AI Water Quality Prediction
  • Generate Reports
  • Cloud Monitoring

🛠 Technologies Used

  • HTML
  • CSS
  • JavaScript
  • Firebase
  • ESP32
  • Arduino IDE
  • Machine Learning
